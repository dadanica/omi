# omi

> 把时间留给自己，把空间留给重要的人。

Omi 是一个以自我探索与深度关系为核心的个人数字空间原型。它帮助人们保留个人思考，并以尊重边界的方式维系与生命中重要之人的连接；AI 只用于协助回顾、提问与理解，不能替用户定义人或关系。

## 当前仓库

这是仅在本机运行的小程序交互预览，包含共同聊天、omi 私聊和记忆权限验证。

当前能力包括：

- 首页右滑进入提醒与灵感。提醒最多 10 条，灵感可查看完整列表。
- 共同记录包含手动日历、愿望与约定、双面喜好卡及收藏的聊天原话。
- 近期事项显示 14 天内的日程及聊天中带明确日期的安排，也显示未过期的有日期愿望。
- 本机消息存储、来源查询、关键词检索及删除。
- 面向体验数据的身份切换与共同空间演示。
- 记忆仅为原始记录索引；不伪造 AI 回复或总结。

## 运行

需要 Python 3.9+，不需要第三方 Python 依赖。

```sh
python3 -B outputs/cute-meow-prototype/app.py --port 8879
```

然后打开 `http://127.0.0.1:8879/`，选择“先体验一下”。服务只监听本机；体验数据与身份均为虚构，切勿输入真实隐私。

## 验证

```sh
python3 -B -m unittest discover -s outputs/cute-meow-prototype -p test_preview.py
python3 -B -m unittest discover -s outputs/memory-backend -p test_backend.py
node outputs/memory-lab/test.cjs
```

## 方向与边界

Omi 优先服务三件事：持续认识自己、深化重要关系、将理解带回真实生活。它不以陌生人匹配、公开展示、互动数量或用户停留时长为目标；不将记录与记忆作为最终目的；也不以 AI 替代真实关系、替用户作出关系判断。

日程线索由本地日期规则检出。正式微信登录和 AI 尚未接入。
