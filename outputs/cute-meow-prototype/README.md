# omi · 可操作界面第一版

这是微信小程序的浏览器交互预览，不是独立 APP 或已发布小程序。页面连接本机 Python + SQLite 后端；沿用上一轮的身份、空间与消息权限代码。所有初始人物和记录均为虚构。

当前预览：<http://127.0.0.1:8879>。只在运行服务的这台电脑上访问，不是公网网址，也不能直接用手机打开。

## 先体验这五件事

1. 首页进入共同空间，发送一句话；切换到阿树（B），能看到同一段共同聊天。
2. 在桐桐（A）的个人空间发送一句话；切换到阿树（B），个人空间没有这条记录。
3. 点击咪头像，进入独立私人对话。可以保存提问，但不会生成假 AI 回复。
4. 在个人聊天点击“翻翻记忆”，触屏设备也可在消息间空白区域向右滑。点击“查看原文”回到来源详情。
5. 打开右上角菜单，查看弧形侧栏、猫咪档案、空间与隐私；按 Esc、点击遮罩或关闭按钮可以退出。

原始消息详情支持本人删除，需要再点一次确认；关联索引随之失效。它是真实删除本机演示记录，刷新不会恢复。

## 启动与测试

在此目录执行（保留同级 `memory-backend/`）：

```sh
python3 -B app.py --port 8879
```

默认数据在 `runtime/preview.sqlite`，首次启动生成虚构样本，以后保留用户在预览中写入的内容。请不要输入真实隐私。服务器只监听 127.0.0.1。

```sh
python3 -B test_preview.py
node --check static/app.js
```

本轮 14 项接口集成测试全部通过，使用独立临时数据库，不污染体验数据。覆盖三个会话、身份切换、共同历史、保存—索引—来源—删除、重启保存、无假 AI 回复，以及 cookie、跨域写入和路径访问防护。

**验收限制：** 本地服务已启动，但浏览器工具访问预览未获批准，因此没有完成真实浏览器点击、截图、手机布局、手势与视觉验收。接口测试不能替代这些检查。后续根据用户可见效果继续迭代。

## 实现边界

体验身份选择仅面向本机虚构数据；`/demo/session` 不是真实身份认证，不得用于上线。会话在 HttpOnly、SameSite cookie 中保存；真实产品需改为微信登录及正式会话生命周期。退出空间、多人邀请和媒体权限还未在本预览实现。

源码中的所有用户文本均通过 textContent 展示。后端读取每次鉴权；切换身份时清空页面和弹窗，异步页面及来源请求使用版本号，避免迟到结果回写到新身份视图。仍需真实浏览器回归验证。
