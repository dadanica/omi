# omi记忆规则验证台 01

本轮按用户选择只验证规则，不接入真实模型。20 条虚构消息覆盖 2026 年 5—10 月，分类、主体与偏好更新关系均为人工标注。页面内展示规则计算结果，不提供预设 AI 关系建议。

## 如何复现

在本目录执行 `node test.cjs`。需要 Node.js，无第三方依赖。命令会运行测试并更新 `test-results.json`，任何失败都会返回非零退出码。`engine.js` 是演示和测试共用的规则实现。

## 可以体验

- 在 A 私人单聊、B 私人单聊、共同群聊、未授权用户之间切换。
- 查看最早讨论、历史偏好、本人表达与转述/推测的区别。
- 以资源 ID 尝试读取另一人的私人消息或私人单聊。
- 删除本人记录，观察检索与关联赠礼变化。
- 撤销赠礼授权，检查接收者只能访问选中片段，不能打开完整私人来源。
- 查找不存在的事件，观察无依据结果。

## 当前测试不能证明的事情

这是客户端内存实验，不是已上线后端。全部样本均发送给演示页面，因此绝不能用于真实秘密；研究者视角故意允许检查完整虚构数据。上下文选择是模拟身份，不是认证。

检索使用预定义关键词及人工标签，不是语义检索。分类及 supersedes 关系不是模型提取。当前偏好仅覆盖显式更新的测试情形，不支持真实世界冲突自动消解。

删除会让本次实验的读取、检索和礼物派生视图失效；没有真实对象存储、数据库、向量索引、队列、备份或缓存，不能宣称完整删除传播通过。重置可恢复虚构样本。未来生产系统不得让用户凭按钮自报身份。

群聊里的引用指令在本轮只被当作字符串；其测试证明规则层没有执行它，不能证明真实模型已抵御提示注入。

## 下一阶段的独立验证

1. 选定模型服务后，接入真实提取与回答，保留相同样本及来源 ID。
2. 增加未参与调试的中文测试集。模型评测与规则测试分开报告。
3. 同模型、同数据比较长上下文和检索方案，记录证据召回、事实支持、时间/主体归因、未知拒答、人工关系建议评审、延迟与实际费用。
4. 将规则迁移到服务端并加入真实认证、数据库权限、媒体读取、撤销并发及删除传播测试。
5. 所有被发现的越权问题必须修复才能进入真实用户试用；有限测试通过不等于不存在其他漏洞。

本轮没有改变产品定位或删减三个核心入口。此验证台是技术研究工具，不是小程序界面定稿。
